# FlyRank Book Scraper

A polite, idempotent web scraper that extracts structured book data from Books to Scrape using Node.js native fetch, Cheerio, and Zod validation. This project was developed as part of the FlyRank Internship Assignment, completing Stages 1 through 6.

## Project Location

All source code, configuration, and output files for this scraper are located in the `Week5/scraper/` directory.

## Quick Start

Clone the repository and execute the scraper with the following commands:

```bash
git clone https://github.com/Adarsh-bhandari1/FlyRank.git
cd FlyRank/Week5/scraper
npm install
node src/main.js
```
